How this website works

Every file, the layout grid and the breakpoints, in one place.

Files

showcase/
├── index.html       intro page (no dashboard shell)
├── dashboard.html   overview
├── products.html    product grid
├── order.html       order form
├── docs.html        this page
└── css/styles.css   the one stylesheet
Relative path. Pages link css/styles.css, not /css/styles.css, so they also work when opened straight from disk.

The layout grid

Only .app defines the layout. Every other block says which area it belongs in.

.app {
  display: grid;
  grid-template-areas:
    "side nav  nav  nav"
    "side main main hist"
    "side prof prof user"
    "side foot foot foot";
}

Breakpoints

Above 1180px: four columns. Up to 1180px: the history panel drops below the main panel. Up to 860px: one column, and the sidebar becomes a scrollable strip. Nothing is hidden, it only reflows.

Adding a product

Copy one .card in products.html, change the name, description and price, and use light, medium or dark on the thumbnail.
